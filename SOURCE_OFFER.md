# Written offer for corresponding source

For every executable or object-code artifact distributed in this repository,
the repository maintainer offers to provide the complete corresponding
machine-readable source code, including the project-specific modifications and
available build scripts, under the applicable component licenses.

This offer is valid to any third party for at least three years from the last
distribution of the covered artifact. The source will be provided for no more
than the reasonable physical cost of transferring it. Open a GitHub issue in
this repository and request the corresponding source using the artifact path
and SHA-256 from `manifest/baseline-manifest.json`.

The retained source records include the exact RBF build-input manifests and
source commits, the modified Base and Jetson bridge sources and patches, and
the Jetson `mac80211_hwsim` source/build boundary. This offer does not cover
unrelated private operator receipts, credentials, or live RF measurements.
